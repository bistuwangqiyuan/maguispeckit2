## 1. 功能概述

### 1.1 功能名称

石油用防爆工业磁检测仪器Web界面系统（MagSpecKit Web Interface）

### 1.2 功能描述

为石油管道无损检测行业打造一个专业级的Web化磁漏检测仪器操作界面。系统需要完整复现现有硬件设备的操作界面设计（DOPPLER NOVASCAN工业风格），并实现所有核心检测功能，包括：实时数据采集、磁信号波形显示、项目管理、检测参数配置、数据分析与报告生成。系统必须符合国际NDT标准（ISO 9934、ASTM E709、EN 1290），确保检测结果的准确性和可追溯性。

### 1.3 业务价值

- **安全保障**: 及时发现石油管道缺陷，预防泄漏和爆炸事故
- **合规要求**: 满足国际标准和行业监管要求
- **成本降低**: Web化部署降低硬件成本，远程访问减少现场人员需求
- **数据资产**: 集中存储检测数据，便于历史追溯和趋势分析
- **操作便捷**: 熟悉的工业界面降低操作人员培训成本

## 2. 用户角色与场景

### 2.1 用户角色

1. **检测工程师（主要用户）**
   - 负责现场或远程操作磁检测设备
   - 需要实时查看波形、判断缺陷
   - 配置检测参数、管理检测项目

2. **质量主管**
   - 审核检测报告
   - 查看历史检测数据
   - 监督检测流程合规性

3. **系统管理员**
   - 管理用户权限
   - 配置系统参数
   - 维护设备校准数据

4. **数据分析师**
   - 导出历史数据进行趋势分析
   - 生成统计报表

### 2.2 核心用户故事

**US-001**: 作为检测工程师，我希望看到与原硬件设备一致的操作界面，以便无需额外培训即可上手操作。

**US-002**: 作为检测工程师，我希望实时查看磁信号波形图，以便即时判断管道是否存在裂纹、腐蚀等缺陷。

**US-003**: 作为检测工程师，我希望创建和管理检测项目，以便组织不同管道段的检测工作。

**US-004**: 作为检测工程师，我希望配置检测参数（增益、闸门、触发条件），以便适应不同材质和厚度的管道。

**US-005**: 作为质量主管，我希望查看符合ISO 9934标准格式的检测报告，以便向监管部门提交合规文档。

**US-006**: 作为检测工程师，我希望系统自动保存检测数据，以便意外中断时不会丢失数据。

**US-007**: 作为数据分析师，我希望导出CSV/PDF格式的历史数据，以便进行外部分析。

## 3. 功能需求

### 3.1 界面复现（UI Replication）

#### FR-UI-001: 工业风格界面
系统界面必须完整复现DOPPLER NOVASCAN硬件设备的界面设计：
- 橙黑配色方案（橙色 #FF6B35，深灰 #2D2D2D，黑色 #000000）
- 左侧垂直工具栏（播放、上传、DISP、主、GATE、VPA按钮）
- 右侧垂直快捷栏（返回、SAVE、MENU按钮）
- 中央主显示区域（波形图 + 数据表格）
- 顶部状态栏显示设备信息和实时参数
- 底部导航栏
- 橙色边框效果和工业质感阴影

**验收标准**:
- 界面与参考图片的视觉相似度≥95%
- 按钮尺寸、间距、圆角与原设计一致
- 响应式布局支持1024×768到4K分辨率

#### FR-UI-002: 响应式适配
界面必须适配不同屏幕尺寸：
- 桌面端（1920×1080及以上）：完整显示所有功能区域
- 工业平板（1024×768）：保持关键功能可操作
- 触摸屏优化：按钮热区≥44×44像素

**验收标准**:
- 在5种常见分辨率下测试通过
- 触摸操作响应时间<100ms

### 3.2 项目管理（Project Management）

#### FR-PM-001: 项目创建
用户可以创建新的检测项目，包含以下信息：
- 项目名称（必填，唯一）
- 管道编号/位置
- 检测日期时间（默认当前）
- 管道材质（选择：碳钢、不锈钢、合金钢）
- 管道规格（外径、壁厚）
- 检测标准（ISO 9934-1、ASTM E709、EN 1290）
- 检测人员
- 备注信息

**验收标准**:
- 创建项目操作在3步内完成
- 表单验证错误提示清晰

#### FR-PM-002: 项目列表与筛选
用户可以查看所有项目，支持：
- 按日期范围筛选
- 按项目名称/管道编号搜索
- 按状态筛选（进行中、已完成、已归档）
- 排序（最新、最旧、名称）

**验收标准**:
- 列表加载时间<2秒（100个项目内）
- 搜索响应时间<500ms

#### FR-PM-003: 项目详情与编辑
用户可以查看项目详情，编辑项目信息（仅限进行中项目），删除项目（需二次确认）。

**验收标准**:
- 已完成项目信息不可编辑
- 删除操作有明确的二次确认提示

### 3.3 数据采集（Data Acquisition）

#### FR-DA-001: 实时数据采集
系统连接磁检测探头，实时采集磁信号数据：
- 采样率：1kHz - 100kHz可配置
- 通道数：支持1-4通道
- 数据格式：时间戳 + 电压值（mV）
- 采集模式：连续采集 / 触发采集

**验收标准**:
- 数据采集延迟<10ms
- 数据丢包率<0.1%
- 支持至少30分钟连续采集

#### FR-DA-002: 触发条件配置
用户可以配置触发条件：
- 触发源：通道1-4 / 外部触发
- 触发电平：-10V到+10V
- 触发边沿：上升沿 / 下降沿
- 预触发：0-50%

**验收标准**:
- 触发响应时间<5ms
- 触发配置保存后立即生效

#### FR-DA-003: 数据存储
采集的数据自动保存到数据库：
- 每个检测点存储：时间戳、波形数据、参数快照
- 支持断点续存
- 数据完整性校验

**验收标准**:
- 数据保存成功率≥99.9%
- 断电后重启可恢复未保存数据

### 3.4 波形显示（Waveform Display）

#### FR-WD-001: 实时波形图
主显示区域实时绘制磁信号波形：
- X轴：时间（可配置显示窗口：1ms - 10s）
- Y轴：电压（自动或手动刻度）
- 背景：黑色（#000000）
- 网格：可显示/隐藏，网格颜色：深灰（#333333）
- 波形颜色：黄色（#FFD700）用于正常信号，红色（#FF0000）用于超阈值信号
- 刷新率：30 FPS

**验收标准**:
- 波形显示延迟<100ms
- CPU占用率<30%
- 支持缩放（滚轮）和拖动（鼠标）

#### FR-WD-002: 闸门（Gate）标记
在波形图上显示闸门区域：
- 支持A/B两个闸门
- 闸门显示为半透明矩形（橙色 alpha=0.3）
- 闸门可拖动调整位置和宽度
- 显示闸门内信号统计值（峰值、均值、RMS）

**验收标准**:
- 闸门位置精度±1个采样点
- 拖动操作流畅（≥30 FPS）

#### FR-WD-003: 缺陷标注
用户可在波形图上标注疑似缺陷位置：
- 点击波形添加标注
- 标注类型：裂纹、腐蚀、焊缝、疑似
- 标注显示为竖线 + 图标
- 可添加文字备注

**验收标准**:
- 标注位置保存精确到采样点
- 每个检测点支持≥20个标注

### 3.5 参数配置（Parameter Configuration）

#### FR-PC-001: 增益调节
用户可调节信号放大倍数：
- 范围：0dB - 80dB
- 步进：1dB 或 0.1dB
- 方式：滑块 / 数字输入 / ±按钮

**验收标准**:
- 增益调整后波形立即更新
- 增益值保存到项目参数

#### FR-PC-002: 滤波器设置
用户可配置信号滤波：
- 高通滤波：0.1Hz - 10kHz
- 低通滤波：1kHz - 100kHz
- 陷波滤波：50Hz / 60Hz工频干扰

**验收标准**:
- 滤波器参数可保存为预设
- 滤波效果实时预览

#### FR-PC-003: 探头参数
用户可配置探头信息：
- 探头型号（下拉选择）
- 探头频率
- 探头尺寸
- 校准日期
- 校准证书编号

**验收标准**:
- 探头信息与检测数据关联存储
- 过期校准证书显示警告

### 3.6 文件管理（File Management）

#### FR-FM-001: 文件树导航
左侧边栏显示文件树结构：
- 根目录：项目名称
- 子目录：检测日期 / 管道段
- 文件：检测记录（显示缩略波形图）

**验收标准**:
- 文件树支持展开/折叠
- 单击文件加载对应波形数据

#### FR-FM-002: 数据导出
用户可导出检测数据：
- CSV格式：时间戳 + 各通道电压值
- PDF报告：包含波形图、参数表、缺陷标注
- 原始数据：二进制格式（.dat）

**验收标准**:
- 导出100MB数据<30秒
- PDF报告包含数字签名（可选）

#### FR-FM-003: 数据导入
用户可导入历史数据：
- 支持CSV、DAT格式
- 自动识别数据格式
- 导入进度提示

**验收标准**:
- 导入错误数据有明确提示
- 导入过程可取消

### 3.7 报告生成（Report Generation）

#### FR-RG-001: 标准化报告

- 报告封面：项目信息、检测日期、检测人员

**验收标准**:
- 报告生成时间<1分钟（50个检测点）
- 报告格式符合ISO 9934-1要求

#### FR-RG-002: 自定义模板
管理员可创建和编辑报告模板：

- 管道规格（外径、壁厚）
- 检测标准
- 创建时间
- 更新时间
- 状态（进行中/已完成/已归档）
- 创建人

#### 实体2: 检测记录（TestRecord）
- 记录ID（UUID，主键）
- 项目ID（外键）
- 检测时间
- 探头信息
- 检测参数（JSON：增益、滤波器、采样率等）
- 波形数据（BLOB或外部存储URL）
- 缺陷标注（JSON数组）
- 检测人员
- 审核状态

#### 实体3: 缺陷标注（DefectAnnotation）
- 标注ID（UUID，主键）
- 记录ID（外键）
- 位置（时间点或采样点索引）
- 缺陷类型（裂纹/腐蚀/焊缝/疑似）
- 严重程度（轻微/中等/严重）
- 备注
- 标注人
- 标注时间

#### 实体4: 用户（User）
- 用户ID（UUID，主键）
- 邮箱（唯一）
- 密码哈希
- 姓名
- 角色（检测工程师/质量主管/系统管理员）
- 创建时间
- 最后登录时间

#### 实体5: 操作日志（AuditLog）
- 日志ID（UUID，主键）
- 用户ID（外键）
- 操作类型（登录/创建项目/修改参数/导出数据等）
- 操作对象（项目ID/记录ID等）
- 操作详情（JSON）
- IP地址
- 时间戳

### 5.2 实体关系

- 一个项目包含多个检测记录（1:N）
- 一个检测记录包含多个缺陷标注（1:N）
- 一个用户创建多个项目（1:N）
- 一个用户生成多条操作日志（1:N）

## 6. 验收场景

### 场景1: 完成一次完整的管道检测流程

**前置条件**: 
- 用户已登录
- 探头已连接并校准

**操作步骤**:
1. 用户创建新项目"西气东输一线-001段"
2. 填写管道信息（碳钢，Φ1016mm×12mm）
3. 配置检测参数（增益40dB，采样率10kHz）
4. 启动数据采集
5. 实时查看波形，发现异常信号
6. 在异常位置添加缺陷标注"疑似腐蚀"
7. 停止采集并保存数据
8. 生成PDF检测报告
9. 提交报告供质量主管审核

**预期结果**:
- 项目创建成功，项目列表中可见

## 12. 术语表

| 术语 | 定义 |
|------|------|
| MFL | Magnetic Flux Leakage，磁漏检测 |
| NDT | Non-Destructive Testing，无损检测 |
| ISO 9934 | 国际标准化组织发布的磁粉检测标准 |
| ASTM E709 | 美国材料与试验协会发布的磁粉检测标准 |
| RLS | Row Level Security，行级安全策略 |
| 闸门（Gate） | 波形分析中选定的时间窗口，用于统计信号特征 |
| 增益（Gain） | 信号放大倍数，单位dB |
| 触发（Trigger） | 开始数据采集的条件（电平、边沿等） |
| 采样率 | 每秒采集的数据点数，单位Hz |
